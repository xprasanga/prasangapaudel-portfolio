Project overview

Exploring a relational retail database

This project demonstrates a basic SQL workflow from database construction to analytical queries. The database contains customers, products, orders, and order items, allowing the analysis to connect customer behavior with products and sales.

The dataset is synthetic and was created specifically for portfolio demonstration purposes.

03 · Join & Aggregate

Which products generate the most revenue?

This query combines order items with product information and calculates total revenue for each product.

SQL code
SELECT
    p.product_name,
    p.category,
    SUM(oi.quantity) AS units_sold,
    ROUND(SUM(oi.quantity * p.price), 2) AS revenue
FROM order_items AS oi
JOIN products AS p
    ON oi.product_id = p.product_id
GROUP BY
    p.product_id,
    p.product_name,
    p.category
ORDER BY revenue DESC;

04 · Group & Summarize

Which product categories generate the most revenue?

Grouping products by category allows us to compare the overall performance of different parts of the product portfolio.

SQL code
SELECT
    p.category,
    SUM(oi.quantity) AS units_sold,
    ROUND(SUM(oi.quantity * p.price), 2) AS revenue
FROM order_items AS oi
JOIN products AS p
    ON oi.product_id = p.product_id
GROUP BY p.category
ORDER BY revenue DESC;

05 · Multiple Joins

Who are the highest-value customers?

This query joins four tables to calculate the total spending and number of orders associated with each customer.

SQL code
SELECT
    c.customer_name,
    c.city,
    COUNT(DISTINCT o.order_id) AS number_of_orders,
    ROUND(SUM(oi.quantity * p.price), 2) AS total_spent
FROM customers AS c
JOIN orders AS o
    ON c.customer_id = o.customer_id
JOIN order_items AS oi
    ON o.order_id = oi.order_id
JOIN products AS p
    ON oi.product_id = p.product_id
GROUP BY
    c.customer_id,
    c.customer_name,
    c.city
ORDER BY total_spent DESC;

06 · Date Analysis

How do sales change over time?

The SQLite strftime() function is used to extract the year and month from each order date and summarize monthly sales.

SQL code
SELECT
    strftime('%Y-%m', o.order_date) AS month,
    COUNT(DISTINCT o.order_id) AS number_of_orders,
    ROUND(SUM(oi.quantity * p.price), 2) AS revenue
FROM orders AS o
JOIN order_items AS oi
    ON o.order_id = oi.order_id
JOIN products AS p
    ON oi.product_id = p.product_id
GROUP BY month
ORDER BY month;

07 · Subquery

What is the average order value?

A subquery first calculates the total value of each individual order. The outer query then calculates the average across orders.

SQL code
SELECT
    ROUND(AVG(order_total), 2) AS average_order_value
FROM (
    SELECT
        o.order_id,
        SUM(oi.quantity * p.price) AS order_total
    FROM orders AS o
    JOIN order_items AS oi
        ON o.order_id = oi.order_id
    JOIN products AS p
        ON oi.product_id = p.product_id
    GROUP BY o.order_id
);
Result
Average order value
$424.13
Interpretation: The average order in the synthetic retail dataset is worth approximately $424.13.
